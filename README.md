# Portfolio Israel Martínez Olmedo

Portfolio minimalista de diseñador de producto senior, construido con React, TypeScript, Tailwind CSS y Motion.

## 🚀 Características

- ✨ Diseño minimalista moderno
- 🎨 Sistema de diseño coherente con Tailwind CSS v4
- 🎭 Animaciones avanzadas con Motion (Framer Motion)
- 📱 Completamente responsive
- 🛣️ React Router para navegación multi-página
- 🎯 Case studies detallados de proyectos reales

## 📦 Instalación

```bash
# Instalar dependencias
pnpm install

# Modo desarrollo
pnpm dev

# Build para producción
pnpm build

# Preview del build
pnpm preview
```

## 🌐 Deploy en GitHub Pages

Este proyecto está configurado para desplegarse automáticamente en GitHub Pages mediante GitHub Actions.

### Configuración:

1. Ve a **Settings > Pages** en tu repositorio de GitHub
2. En **Source**, selecciona **GitHub Actions**
3. Haz push a la rama `main` y el deploy se ejecutará automáticamente

La página estará disponible en: `https://[tu-usuario].github.io/[nombre-repo]/`
